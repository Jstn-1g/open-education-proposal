# Learning Lab: scope and review

Fraction Bridge and Clockwork Lab are openly inspectable design examples for **adult review**, not validated lessons, a classroom-ready product or a service recruiting children. The age labels describe tentative design starting points, not individual readiness or suitability. Jstn-1g authorized this public demonstrator after reviewing its direction; that is not line-by-line human inspection or qualified specialist approval.

The focused homepage starts with an empty bridge: take either of two equal pieces to build a path for the fox marker. Tapping or keyboard activation places a piece; desktop dragging onto the gap is an optional shortcut. There is no required Split or Check action. A full bridge automatically opens the crossing; partial bridges do not. Rebuilding with four quarters is optional and keeps the same whole-width span. The native fox marker is temporary artwork.

The full playground retains mixed-piece construction, additional fraction targets, length/mass comparison, optional predictions, model explanations and evidence notes. Help, undo/reset and Simple view stay available. Opening the full playground preserves the selected example and Simple preference, but starts fresh; there is no saved progress. The full playground's partial-target flags are a different exploration, not a promise that the fox can cross an incomplete bridge.

The exact fraction model uses integer eighths. The pendulum uses the ideal small-angle period formula with fixed gravity 9.81 m/s² and 8° amplitude: 0.5, 1 and 1.5 m give approximately 1.42, 2.01 and 2.46 seconds, independent of mass in this model. It ignores friction, air resistance, string mass and stretch. A computed animation illustrates assumptions; it is not experimental evidence.

Research sources, counterevidence and paper alternatives are linked in the playground's “Evidence & limits” section. Neither successful clicks, enjoyment nor matching pieces establishes learning, retention or transfer. No qualified educator, accessibility-practitioner or child-user review is claimed.

## Runtime boundaries

No accounts, backend, AI service, analytics, storage, recordings or network submissions. Inputs exist in page memory and reset on reload. The chosen example may remain in the URL. GitHub Pages processes requests under its hosting/privacy terms. Private reporting remains human-owned.

Only the homepage allows the same-origin learning frame. Five routes allow self-hosted scripts: the homepage, Learning Lab, Activity Library, Activity Studio editor, and activity player. All five prohibit application connections and form submissions. Other reading pages keep their restrictive no-script policy. GitHub Pages does not supply the local development server's response headers; embedded meta CSP is the policy shipped by this project. It cannot enforce `frame-ancestors` or response-only permissions directives.

Initial Simple view skips the rendering engine/art downloads. Missing graphics fall back to native controls. Without JavaScript, explanations and static examples remain, but interaction is disabled. No low-powered physical-device or full browser/assistive-technology compatibility guarantee is made. See [asset provenance and the initial transfer budget](../learning-lab/ASSETS.md).

## Verification and remaining limits

The release uses reproducible build/link/manifest tests, exact model tests, and bounded desktop/mobile keyboard, enlarged-text, spacing, reduced-motion, forced-color, no-JavaScript and graphics-failure checks. Actual release results must be tied to the reviewed pull request and deployment; merely listing tests is not a passing run.

Screen-reader use, real browser zoom, disabled-user comprehension, physical devices, educational effectiveness and institutional adoption still need evaluation. This is not a security certification, WCAG conformance statement or evidence that the model works equally well for every learner. Report a barrier or challenge one design choice through the contribution guide, without learner records or private information.
