How to contribute this draft
Share a draft with the community

First try every challenge and check the learning goal. Download your file, then propose it for review. Submitting is a separate action on GitHub; it currently needs a GitHub account.

  1. Copy the recipe below or open your downloaded JSON file as text.
  2. Open an activity proposal and paste the recipe in its requested section.
  3. Explain what you changed and what still needs review. A maintainer decides whether it joins the library.
